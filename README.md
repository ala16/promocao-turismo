# Landing page: Curso de Promoção e Comercialização de Turismo Rural

Página para celular que divulga o curso gratuito e presencial em Joanópolis/SP
(aulas 25/11, 26/11, 02/12, 03/12 e 10/12, no O Buscador Místico).

## Trocar o número do WhatsApp

Abra `index.html`, procure `WHATSAPP_NUMERO` (perto do fim do arquivo) e troque
pelo número no formato `55` + DDD + número, só dígitos. Ex.: `5511987654321`.
Todos os botões de inscrição usam esse número.

## Publicação

Cada push na `main` publica o site pelo GitHub Pages (workflow em
`.github/workflows/pages.yml`). Em *Settings > Pages*, a fonte deve estar como
**GitHub Actions**.
